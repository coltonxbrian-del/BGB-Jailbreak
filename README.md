# BGB.JAILBREAK Command Center

A mobile-first installable web app (PWA) starter built with plain HTML, CSS and JavaScript.

## Publish with GitHub Pages
1. Create a new GitHub repository named `bgb-jailbreak`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/bgb-jailbreak/`.

## Install on iPhone
1. Open the published HTTPS URL in Safari.
2. Tap Share.
3. Choose **Add to Home Screen**.
4. Tap Add.

## Notes
- The app is a client-side PWA, not a native compiled iOS app.
- It does not execute code, connect to an AI model, or access device-level developer features.
- Settings and checklist selections are local to the browser session; theme and motion preferences are saved locally.
- For a real AI code assistant, connect a secure backend. Never place private API keys in browser JavaScript.
